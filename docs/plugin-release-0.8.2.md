# 抖音备份 0.8.2

媒体 403、临时网络错误与限流的自动重试上限调整为 5 次（初次请求之外），指数退避并加入抖动。403 从 2.5 秒开始，普通网络错误从 2 秒开始，单次最长 30 秒；429 从 15 秒开始，单次最长 5 分钟，并尊重服务端 Retry-After。重试中可随时暂停；最高画质地址仍优先，403 用尽重试后先刷新地址再考虑回退。

三个分类各有目录：`data/喜欢`、`data/收藏`、`data/关注/作者名_UID`。只有关注下载按作者分目录，同名作者用 UID 区分。已在另一个来源下载的媒体直接复制本地文件到当前分类，不重复走网络；作品数量仍按作品 ID 去重，文件占用按实际副本统计。

整理保留分类边界，只删除内容校验相同的重复副本，先持久保存新引用，再移除旧文件。跨分类的必要副本保留。作者信息优先使用 UID、任务记录和唯一的历史姓名匹配；不能确认身份的历史作者会保留提示。

本地离线维护脚本默认仅核对，可按最多 25 秒一批继续。应用前保存原始状态；旧“点赞”目录同盘改名为“喜欢”，通过持久重放意图保护路径切换。未入库的独有残留移到隐藏元数据目录中的隔离区，保留相对路径，便于恢复。维护期间阻止新扩展写入。

验证覆盖退避五次后恢复、次数用尽与暂停、分类路径隔离、历史作者归档、跨来源副本保留、重复内容校验、未知文件隔离以及完整备份引用可读。
