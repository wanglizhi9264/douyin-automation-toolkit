# 抖音备份 0.8.8

整轮结束直接记录成功和失败。未成功作品留在任务和资料库中，下次点下载时按最新列表检查。媒体 403 在第一次失败后让出下载位置。临时网络错误仍可在 2 秒响应预算内短重试一次。404/410 若有下一画质候选，可在同一预算内尝试，单段最多两次媒体请求。429 继续遵守服务器冷却。

列表检查是一个生产者，两路媒体下载消费同一有界队列。作品详情与列表使用各自串行请求队列和间隔，共用接口 429 冷却。等待队列的请求在中止时立即返回，取消的请求轮到时不会发送。

暂停立即发出中止信号，等在途文件写入和进度日志收尾后释放库锁。暂停跳过全库快照压缩与自动报告生成。正常收尾压缩快照并自动更新报告，暂停后可在资料库手动更新。已开始的磁盘写入仍需完成。

其余数据格式和目录规则见 [实现基线](implementation-spec-0.8.7.md) 和 [当前产品规格](plugin-product-spec-v0.3.md)。
