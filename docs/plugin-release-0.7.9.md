# 抖音备份 0.7.9

画质升级的触发条件以已保存标记为准。`best` 立即跳过；`degraded` 和 `fallback` 才比较候选；`unknown` 或缺标记保持不自动下载。回退到同画质镜像、同画质候选不触发传输。

检查门槛位于来源入队和媒体执行两层。即使旧任务中残留升级队列，媒体当前已标记最高也不会读取详情或传输。成功达到最高后正常写入 `best`，后续列表即使出现更大尺寸也不再触发升级。同一媒体段已有最高版本时，不因其他历史回退副本重复触发。

保留升级失败不动原件、提交新引用后才清理旧媒体、关注选择记忆及逐作者断点继续。验证覆盖最佳/未知标记不触发、更高新候选不覆盖最高标记、降级版本升级、相同质量不重下、失败保留原件和浏览器实际升级。
