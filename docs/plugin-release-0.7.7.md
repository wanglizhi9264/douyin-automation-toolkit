# 抖音备份 0.7.7

进度环原先只在旋转动画终点设置 transform-origin，使旋转中心也参与插值，造成摆动。改为整层SVG固定中心、固定尺寸并旋转，图标与进度环共享中心。外环保留当前作品标识，多段按段累计，避免另一通道加入后分母变化导致跳动。

引擎将字节进度事件与结构状态事件分开；字节事件限频更新媒体行文本、进度条及外环，不再重复计算整库计数和替换整个任务页面。状态、计数变化仍通过原有统一渲染更新。

403媒体错误对最高候选做一次1.5秒起的短暂退避；仍失败时优先刷新一次详情地址，再从最高候选尝试。退避可取消，刷新次数有上限，不对全部403接口盲目重试。429仍采用现有共享冷却，不因403重试而绕开。

新增只重试失败项：从原任务提取未成功且本地未完成的作品，使用现有锁、双下载池和断点媒体逻辑，不访问来源列表。作品详情重新读取，避免重复使用失效媒体地址。原完整列表数量保留；原列表未读完时不宣称全量备份完成。原下载入口仍每次从最新列表开始。

首页删去重复引导，历史数超出当前数时才显示说明；任务页保留核心数据，数量和下载说明折叠，等待下载和未成功分别呈现。失败时优先展示重试按钮。离线报告明确失败重试不等于重新读过完整列表。

验证包含403恢复最高画质、地址刷新、保持429策略，失败/暂不可用作品专门重试及跳过已完成媒体，浏览器动画全周期同心和失败重试不重新分页。
