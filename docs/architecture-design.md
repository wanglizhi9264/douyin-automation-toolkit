# 当前架构与业务规则

更新于 2026-11-10。插件基线 **0.8.9**。详细行为以 [产品规格 v0.3](plugin-product-spec-v0.3.md) 和 [技术实现基线](implementation-spec-0.8.7.md) 与 [0.8.8 实现变更](plugin-release-0.8.8.md) 和 [0.8.9 队列策略](plugin-release-0.8.9.md) 为准；本文作为架构入口。早期审查与旧模块设计保存在 [历史架构](architecture-design-legacy.md)，其中“当前”不再代表本版本。

## 1. 分层

| 层 | 模块 | 边界 |
| --- | --- | --- |
| 展示 | sidebar/modern-app、presentation、style | 路由、选择、显示派生状态；不自己推断持久化成功 |
| 页面桥 | content、injected、shared/events | 取当前账号接口数据，按 requestId 和 AbortSignal 管理请求 |
| 来源 | core/sources、pagination | 列表和详情独立串行节流、账号校验、可靠分页和名单读取 |
| 编排 | core/engine | 库锁、有界队列、两路异步下载、逐作者屏障 |
| 执行 | core/media、shared/download | 归一化分段、画质、流式下载、验证与续传 |
| 存储 | archive/repository、fs、layout、naming | v2 事实源、串行提交、恢复、分类和稳定可读命名 |
| 离线查看/维护 | archive/report、maintenance | 派生报告、闲时统计、去重与迁移；与下载互斥 |

后端独立运行；浏览器临时存储用于目录句柄等，不替代目录内 v2 状态。代码中存在的旧侧栏、私信动作和内部恢复接口不等于现代产品入口。

## 2. 当前关键决策

1. 每次正常启动从最新列表开头检查；远端 cursor 只记录本轮扫描，不作为下一次查新的默认起点。
2. 先读到一页即可下载，不做全列表扫描与确认关卡。容量 64 的队列背压与两路异步消费者约束资源。
3. 作品按全库 ID 识别，sources 保留来源；物理文件按喜欢、收藏、我的关注分开。跨来源副本使用本地复制，不能当重复数据无条件删除。
4. v2 快照、不可变 journal 和交替 head 是事实源。写入失败暂停，不凭 UI 数字或旧索引宣布成功。
5. 最高标记直接跳过，明确降级/回退且有更好候选才升级；升级先暂存、验证、提交新引用，再清理旧文件。
6. 媒体响应及首段数据共享 2 秒预算；持续正常传输可更久，停滞 2 秒中止本尝试。列表 API 有独立等待与限流，不承诺所有操作 2 秒硬返回。
7. 扫描期间空闲下载位重试已冷却的失败项，优先处理新作品。主列表和队列结束后保存本轮结果。媒体限流按 origin 隔离，页面接口共享 API 冷却。暂停保留日志，跳过全库快照压缩。
8. 下载、整理和生成报告使用库锁；维护哈希用 Worker，媒体下载不是多进程。
9. 主页只放目录和三个入口；数量与任务状态在任务页，分类浏览与诊断在本地库.html。

## 3. 三种状态不能混淆

- 平台总量：上次接口/页面观测值，可能近似或缺失。
- 库历史量：已保存作品与来源关系，取消喜欢后仍保留，允许超过平台总量。
- 本轮状态：新检查、跳过、新增、升级、失败和待处理。

当前传输进度不等于整库覆盖率；来源数不直接相加作为全库唯一数；已写入的未完成字节也不等于完成作品。

## 4. 兼容与决策记录

现代数据与目录、重试和升级规则由 [ADR-0004](adr/0004-modern-archive-and-incremental-backup.md) 统一记录；对旧复合键、旧终止游标要求、旧文件命名和跨后端互操作承诺作明确替代。历史 ADR 保留原始依据。

发布只检查变更相关范围，验证层级与仍需实机确认的条件写在 [发布手册](test-release-runbook.md)。历史审查不自动代表现代缺陷仍存在，自动测试通过也不代表历史风险已经全部关闭。
