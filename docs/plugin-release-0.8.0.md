# 抖音备份 0.8.0 简洁版

用户流程统一为下载一次完整检查：喜欢、收藏及所选关注作者每次从头检查到末尾，按本地完成状态和已记录画质决定下载、跳过或升级。关注选择保留，作者仍逐位处理；正常入口不再使用旧作者游标，也不提供失败专门重试与重新检查分支。

首页删去宣传标题、引导段落、容量与作品统计、入口副标题、任务统计条及历史容量缺记录提示，仅保留文件夹和三个下载按钮。任务页保留当前总量、累计、本次数量、当前作者与媒体进度；末尾只保留下载或暂停。数量说明、错误明细、分页诊断等不再渲染到任务操作区域。

完整信息继续写入离线 HTML 看板，暂停/结束自动生成，设置中可手动更新。去掉为首页统计服务的额外账号数量预读，减少不必要请求；账号归属仍由下载引擎检查。

验证覆盖首页不含已删除字段、下载按钮之后没有说明/错误区域、403失败后同一个下载按钮触发完整列表新一轮检查、已是最高的媒体不重下、关注勾选刷新后保留且新一轮从首位作者开始、悬浮拖动与同心外环。单项浏览器测试30秒超时。
