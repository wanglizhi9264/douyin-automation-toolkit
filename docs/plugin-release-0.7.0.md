# 0.7.0 本地试用交付

日期：2026-10-27。基线：0.6.2 / 3533ac2。依据为产品 Spec v0.2 和设计 v1。

## 已落地

- 白色侧栏：首页文件夹、唯一作品数、已完成媒体大小和三个下载入口；任务页分别展示本次保存、已有、读取、待处理、失败和不支持。
- 喜欢/收藏点击即运行；关注分页加载作者、勾选后直接运行。无完整预扫描确认，无 100 个作品批次截断。
- 单页发现与两个媒体消费者交叠，队列上限 64；每个消费者顺序处理一个作品的媒体段。
- 按作品 ID 建全库索引，合并来源关系。两个来源不重复传输同一已完成作品。
- 返回首页、最小化、工具栏隐藏均保留 iframe 和引擎。暂停会取消媒体与桥接等待；记录落盘后才计入保存完成。
- 文件夹 v2 增量日志、校验快照及双头恢复；任务和分段进度存放在本地库。以 Web Locks 阻止同扩展多个标签页并发写同一库。
- 旧索引按 ID 导入；大小未知显示待统计，账号归属冲突阻止写入；无法识别的非空文件夹不初始化为新库。
- 闲时手动整理：核对已记录文件、导入旧 manifest 媒体；Worker 分块哈希比对同作品同段同大小的副本；持久化引用和路径映射后再删除，删除失败可再次整理。
- 蓝色下载归档 SVG、16/32/48/128 PNG 工具栏图标和最小化入口。

## 验证证据

`npm run check`：旧兼容性合约回归、媒体流/Range 等既有运行时检查，以及新引擎运行时测试。旧侧栏 HTML 保留为兼容测试样本，不作为新首页验收，也不打入便携扩展。

新引擎运行时覆盖：137 个作品、先下载后读完列表、最大两路媒体、64 队列上限、跨来源已有跳过、暂停后重开库续传、分页未完整时不报完成、库锁拒绝、损坏最新头恢复前一代、账号绑定校验。

`npm run check:ui`：Playwright，独立临时 Chrome、合成抖音接口、本机 HTTP 媒体流和真实 OPFS。覆盖首页空态、24 个作品、两路传输、最小化/首页不打断、暂停刷新继续并发送 Range、收藏来源复用、23 位作者分页、整理重复文件及再次整理、320/390/736 宽度和浏览器异常检查。截图输出临时目录。可通过 `PLAYWRIGHT_MODULE` 指定 Playwright，`CHROME_EXECUTABLE` 指定浏览器。

## 范围与限制

这是本地试用版本，不是当前用户真实账号的全量验收。未操作真实抖音收藏/点赞/下载。未实测真实抖音吞吐和大库长期资源指标。当前数据以目录记录为准，文件外部变动在手动整理时核对。

本次没有重做旧的喜欢转收藏、私信工具、旧 HTML 本地库页面和下载高级设置。旧模块留在仓库供后续迁移，便携包排除旧侧栏入口及运行脚本。后端未改为 v2，不支持与本版共用目录同时写入。日志和快照保留用于恢复，尚未加入旧元数据代次的自动回收。
