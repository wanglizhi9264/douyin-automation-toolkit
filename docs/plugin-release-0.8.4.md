# 抖音备份 0.8.4

喜欢/收藏：`作者名 - 精简标题 [短ID].mp4`；关注已有作者目录，文件名为 `精简标题 [短ID].mp4`。多视频/多图片的作品目录也使用这个名称，内部仍按 01、02 编号。封面与对应作品使用相同名称。

短标题取原文案首句，清理换行、链接、提及和话题串；纯话题文案保留话题词。标题最多 30 个字素，作者最多 14 个字素，按 UTF-8 字节约束总文件名，避免表情截断和文件名过长。缺少文案时使用“未命名作品”，缺作者使用“未知作者”。完整文案与完整作品 ID 仍保留在库中。

短 ID 默认取完整作品 ID 的后 8 位。库中名称以忽略大小写的规则检查冲突，碰撞时扩展为后 12 位、16 位直至完整 ID。命名字段首次确定后写入作品记录，昵称、标题变化不触发反复改名，也不改变作品去重和画质标记。

历史命名优先使用已有作者和描述；缺失内容从本地历史文本、作者、视频及下载记录补齐，不联网获取标题、不重新下载媒体。设置中的“整理备份”可批量命名并同步路径，离线脚本使用 --readable-names --layout-only。

迁移前保存原始状态与下载库；同盘移动使用暂存事务和可恢复的批量提交，变更完整作品/文件引用与别名，最后更新 HTML 看板并核对数量、片段、画质与已知文件大小。

文件遍历兼容文件系统返回的 Unicode 分解形式：优先用 NFC 对照记录，遇到特殊组合符号差异时，再用分类、短 ID、片段序号、扩展名和大小定位；候选不唯一时保留原文件。整理可恢复误隔离的已登记文件，并将已消失的空目录视为已完成清理。
