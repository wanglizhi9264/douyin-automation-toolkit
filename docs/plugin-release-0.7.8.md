# 抖音备份 0.7.8

已完成作品不再仅按ID跳过：列表页有更清晰候选，或旧记录明确降级时，进入原有有界双下载池升级。比较可证实的分辨率、帧率及同编码码率；不把跨编码码率、文件大小或未知旧画质直接当作升级依据。升级候选必须优于原版本，不能回退到更差画质。

新媒体写入独立路径；所有目标段验证成功后提交新引用，然后清理不再被引用的旧文件。中途失败保持原记录完整；清理失败留待闲时整理。画质升级与新增作品分别计数。

关注选择以UID和secUid保存在备份库内。作者列表记住选择，显示最近各作者的完成/待处理状态。生产端在作者边界等待该作者下载池清空，消费端也防止跨作者并发；同一作者的媒体保持最多两路。

新任务记录作者进度、列表游标与待下载项。继续时先恢复待处理媒体，再从检查点推进后续作者；最后一位列表已读完而媒体未完也可恢复。“重新检查所选作者”显式从头查新作品。喜欢/收藏维持从最新检查的既有规则。旧版缺少作者检查点时重新核对所选作者，不冒险沿用不完整断点。

验证：720→1080升级、同画质跳过、失败保留原文件、提交后删除旧版本、独立升级计数；作者串行、暂停/重新打开接续、最后一位媒体未完、选择持久化；真实Chrome沙箱刷新后保留勾选并继续完成。未修改真实备份媒体或启动真实账号下载。
