# 抖音备份 0.8.10

可重试失败进入冷却队列。两路消费者优先取新作品，空闲时取到期候补。每次尝试失败后重新计算冷却并放回候补，列表扫描完成后任务仍保持运行。没有可立即下载的作品时，任务显示等待重试。候补耗尽后完成本轮，也可随时暂停。

退避依次为 1、2、4、8、16、30 秒，此后保持 30 秒。429 同时遵守服务器冷却。403 刷新地址后仍被拒绝、404、410、不支持和文件名拒绝保留失败原因。账号、权限及磁盘写入等阻断问题继续按原规则处理。

候补等待计入待下载，当前下载标记重试次数，作品只计一次已检查。扫描关注作者时，切换作者只等已有传输收尾，冷却候补保留。空闲位置仍遵守作者间传输不重叠，末尾按最终结果更新作者统计。

该规则替代 0.8.9 的扫描结束停止候补。暂停仍保存进度日志，下一轮从最新列表检查。基础实现见 [0.8.9 队列策略](plugin-release-0.8.9.md)。
