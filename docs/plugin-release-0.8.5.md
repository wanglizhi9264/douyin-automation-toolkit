# 抖音备份 0.8.5

媒体单项失败采用 2 秒响应预算：等待响应、首段数据和最多一次短退避重试共同使用这份预算，不再对每个候选地址反复进行多轮重试。作品详情刷新也使用这份预算。正常收到数据后允许长媒体持续传输；连续 2 秒无新数据则停止当前尝试，保留已写入字节，继续处理后面的作品。

403、暂时性网络错误的等待仅影响本次请求。媒体 429 按下载域名记录冷却；Retry-After 超过当前预算时立即暂缓该项，不占用工作线程等候。冷却期间其他域名可继续下载。列表接口仍独立遵守其限流，账号、权限、磁盘和索引写入错误仍会安全暂停。

主列表完整读完、首轮队列清空后，自动对失败作品补下一轮，重新获取详情和下载地址，已完成的片段保留。最高画质仍优先，补下不读取来源列表，不增加本轮已检查数量；成功时从失败转为已保存，补下结束仍失败则保留记录，避免无限循环。关注继续保持作者间传输不重叠，作者状态在补下后刷新。

侧栏在自动补下阶段显示“补下中”，没有传输且等待 Retry-After 时显示“等待补下”。暂停也会取消等待和补下。HTML 看板展示补下总量、成功量与余下问题，不增加新按钮。更新时先暂停旧任务，重新加载扩展，刷新抖音网页后开始下载。目录、命名和历史数据格式保持兼容。
