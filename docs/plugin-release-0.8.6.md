# 抖音备份 0.8.6 · 分类报告

报告从统计看板改为可浏览的本地资料库。首页三个入口为我的喜欢、收藏、我的关注，主数字仅表示该来源累计已备份作品数。相同作品可分属多个来源，不能将分类数相加作为去重总量。平台上次读取的列表总量独立标注，未知时不猜测。

喜欢、收藏直接进入所属作品列表；关注先进入本地作者列表，按作者身份分组、支持名称和 UID 搜索，再查看该作者作品。历史记录缺身份时使用已有作者目录或历史分组，不伪造 UID。返回作者列表和返回首页保持清楚；重置只清除筛选，不退出当前分类和作者。

打开媒体优先选择当前来源下已完成的视频、图片；同类型多个文件按自然顺序展示，封面不作为主打开入口。现代分类已有文件时优先对应目录；缺路径的旧记录保留明确提示，不跳到其他来源冒充已保存。原有分页、搜索、状态画质筛选、详情和 CSV 保留。

去重总量、占用、失败原因、画质与运行记录置于默认收起的备份详情，离线报告保持静态快照说明。页面适配窄屏并保留键盘焦点。下载引擎和目录规则延续 0.8.5。
