# 抖音备份 0.7.6

悬浮快捷入口改成围绕主图标展开的三个圆按钮，按所在边缘朝内排列。主图标支持拖动、位置记忆、窗口缩放防出界；拖动不会误触打开面板。菜单开合时主图标保持原位置。

面板和悬浮菜单均恢复关闭按钮。“−”继续后台下载，“×”先中止名单读取、闲时统计及下载请求，保存断点后隐藏 iframe。再次点击工具栏可恢复界面。没有移除 iframe 或丢弃库状态。

细蓝色外环显示当前传输的加权字节进度；检查列表或长度未知时旋转，暂停时静止。不以累计历史备份与当前喜欢/收藏总数的比值伪造进度。

收藏数据按三个口径展示：接口精确总数、抖音页面的近似数、最近完整读取的可访问作品数。页面“我的收藏1.3万”显示“约1.3万”，不会当作精确13000。探测收藏首页可复用于下载，避免重复请求；列表未读完不生成总数。

媒体占用原来只要一个历史作品无大小就隐藏全部数值。改为立即显示已知容量和未核实作品数，空闲时只读清单与文件大小补统计，不读取媒体内容、不哈希、不删除、不修改未知作品的完成状态。开始/恢复下载前会取消并等待统计释放备份库锁。报告采用相同口径。

实际备份只读核对：已知105236666840字节、16个历史作品缺少路径；因此界面显示约98.0 GB已知占用，16项仍未核实。当前平台导航显示收藏1.3万。此次没有启动真实账号下载或修改真实备份记录。
