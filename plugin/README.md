# 抖音收藏与下载工具

Chrome/Edge MV3 插件，当前版本 0.6.2，使用当前抖音页面登录态。后端诊断工具独立运行，不是插件的后台服务。

## 验收与限制（2026-10-09）

请先阅读 [项目业务审查](../docs/project-audit-2026-10-09.md)。以下是现状，不是已修复声明：

- 本地库 HTML 的总数来自展示记录，不能代表整个备份目录；关注被误归为喜欢，历史元数据可能缺失。
- 喜欢、收藏按 scope 重新分页对账；关注先同步作者作品，但每次只下载配置批次，默认 100 条。
- “任务已完成”目前可能只表示扫描/批次结束，不保证没有失败或剩余作品；一键链路须升级结构化完成判定。
- 私信点赞有真实账号副作用；同名身份预校验、请求超时取消和私信阶段暂停尚待补齐，不建议无人值守执行。
- 完成索引与数量缓存不是实时文件校验。手动删文件、后端写库或迁移旧目录后不能盲信旧数量。
- 现有自动检查含源码契约测试；全绿不等于真实账号全链路通过。

## 当前能力

- 在 `www.douyin.com` 页面右侧注入本地侧边栏。
- 打开侧栏后快速读取抖音官方喜欢和收藏总数。
- “一键完整备份”自动寻找“王立志”会话并逐条打开分享；明确未点赞才点击，明确已点赞则跳过，随后编排三个下载阶段。失败和未达历史起点会阻止后续下载，但不会撤销已完成的点赞。
- 分页检查并下载喜欢、收藏中的普通视频、图文、live photo 和接口显式多段视频；已下载作品自动跳过。
- 记住用户授权文件夹，以文件夹记录为准继续下载。
- 复用列表中的最高画质候选，缺失或过期时再获取作品详情。
- 按最高画质候选排序下载视频段、原始图片、可选封面，并导出 manifest、派生数据库及状态；回退或候选历史未知时不能保证最高画质。
- 记录列表、详情、限流、媒体传输、磁盘写入和 UI 各阶段耗时。
- 导入后端脚本进度，并保留继续收藏和审计能力。

## 运行说明

- 首次使用先点“选择文件夹”；后续任务优先复用该目录。
- “下载喜欢视频”和“下载收藏视频”都从第一页重新核对，以文件夹记录跳过已下载项。
- “继续下载”恢复上次作用域，不依赖可能过期的远端游标。
- 最高画质最多尝试 4 个去重候选，失败时按顺序回退。
- 收藏总数优先读取个人资料；缺失时预取并复用收藏第一页，不靠扫描数量一点点假装远端总数。
- 图文保存到 `data/<点赞|收藏>/图片/<awemeId>/<序号>.<扩展名>`。
- 多段视频保存到 `data/<点赞|收藏>/视频/<awemeId>/<序号>.mp4`。
- 每个内容段成功后立即保存检查点；暂停或失败后继续会跳过已完成段。
- 任务结束后查看 `data/.appdata/performance-summary.json` 判断慢在接口、主动等待、网络还是磁盘。
- 喜欢/收藏流式下载连续 8 条失败会熔断；关注通用批次尚无同等的失败完成判定。接口异常、限流和登录失效需查看明确错误，不应只看“已连接”。
- 私信分享点赞直接使用作品弹窗的真实点赞状态，不依赖可能返回 HTTP 200 但缺少作品数据的详情接口；无法确认状态时会停止，避免误操作。

## 数量口径

- 平台总数：账号资料或列表接口的当前值，不保证每条均可下载。
- 本地完成：对应 scope 完成索引的数量；喜欢、收藏、关注不能互相覆盖。
- 本地唯一作品：三个 scope 的完成 ID 并集；不能直接把三个数相加。
- 待下载：应为当前目标集合减该 scope 完成集合；当前首页部分值仍为估算。
- 消失留存：本地喜欢完成 ID 不在最近完整可读列表的部分，包括取消喜欢、私密或不可访问等情况，不是已删除证明。

HTML、`db_*.json` 都是派生展示文件，不能作为断点续传依据。每日轻量备份是当天首次下载任务触发，不是插件关闭时仍运行的定时任务。

## 本地安装

1. 打开 Chrome：`chrome://extensions`
2. 开启开发者模式。
3. 点击“加载已解压的扩展程序”。
4. 选择本仓库的 `plugin` 目录。
5. 打开 `https://www.douyin.com/`，登录后点击扩展图标显示侧边栏。

## 开发命令

```bash
npm run check
npm run zip
```

`npm run zip` 在 `plugin/dist/portable-*/` 生成独立运行文件夹及同名 ZIP；仅包含 manifest、src 和独立安装说明，无后端和登录数据。将 ZIP 发给其他电脑后，按 [跨电脑安装说明](INSTALL.md) 解压并加载即可。新电脑必须重新登录并授权目录，历史媒体需要另行完整复制。打包不会修复上述已知业务缺陷。

浏览器函数运行时回归在后端执行 `npm run test:shares`；真实页面的只读探针及有副作用命令见 [测试与发布](../docs/test-release-runbook.md)。本次没有重新执行真实点赞、收藏或下载。
