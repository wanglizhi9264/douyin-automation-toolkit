# 抖音备份插件：另一台电脑安装说明

这是完整的 Chrome/Edge MV3 未打包扩展目录。无需安装 Node.js、Python、后端或 npm 依赖；不能双击 ZIP 自动安装，也不是 Chrome 网上应用店签名安装包。

## 安装

1. 解压 ZIP 到一个固定位置，例如 `D:\Apps\douyin-toolkit-extension`，不要在压缩包内运行。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”。
4. 选择直接包含 `manifest.json` 和 `src` 的文件夹，不是其外层目录。
5. 打开 `https://www.douyin.com/`，在这台电脑自行登录，刷新页面。
6. 点击插件图标打开侧边栏，点击“选择文件夹”，授权这台电脑上的备份根目录。
7. 单独选择喜欢、收藏或关注作者下载。关注作者需先选择作者范围。

加载后不要移动或删除插件文件夹。更新时先暂停下载，再替换运行文件，在扩展管理页点击“重新加载”，最后刷新抖音页。公司或学校策略禁止开发者扩展时，需要管理员允许。

## 登录、设置与历史备份

- 插件包不包含任何登录 Cookie、浏览器数据库、私信记录、目录权限或下载媒体。新电脑必须重新登录、选择下载目录及关注作者。
- 要继续原电脑的备份，需另外复制整个备份根目录，包括 `data/.appdata`、媒体、manifest 和未完成媒体的 `.resume.json`。只复制插件不会带走历史备份。
- 选择包含 `data` 的备份根目录，不要选择其 `data` 或 `data/.appdata` 子目录，以免生成嵌套目录。
- 账号须与原库绑定账号一致。不要把插件源码目录当媒体备份目录，不要让两台电脑或后端同时写一个共享备份库。
- 如提示目录记录缺失、账号不符或需要重建，先保留原库；当前旧目录的多段未完成扫描存在限制，不要据此删除媒体。

## 当前版本的已知限制

本包是当前源码的便携调试构建，不代表完整业务已通过验收。

- 本地库 HTML 的历史数量与来源分类存在已知问题，关注作品可能误显示为喜欢；不要据此判定备份完整性。
- 关注作者下载每次只处理一个配置批次（默认 100 条），“已完成”可能只是批次完成。
- 私信一键备份当前固定寻找“王立志”，不是任意用户通用功能。身份预校验、超时取消尚未完善；其他账号不建议使用，不能无人值守运行。
- 私信点赞有真实账号副作用，已经点赞不应再次点击；失败不会撤销此前发生的点赞。该流程未通过全历史到三类下载的完整验收。
- 索引与数量缓存不是实时文件完整性校验；强制关浏览器、外部删文件或后端写库后可能需要额外核对。

建议先在测试目录验证少量作品，再用于正式备份。安装成功不等于抖音登录态、接口、风控和全部业务均可用。
